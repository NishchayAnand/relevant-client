Candlestick chart is another key data structure in the market data processor to produce market data. 
We model this with a candlestick class and a candlestick chart class. When the interval for the 
candlestick has elapsed, a new candlestick class is instantiated for the next interval and added to 
the linked list in the candlestick chart instance. Tracing price history in candlestick charts for 
many symbols at many time intervals consumes a lot of memory. As a solution, we can use pre-allocated 
ring buffers to hold sticks to reduce the number of new object allocations.
