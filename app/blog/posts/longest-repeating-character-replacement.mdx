You are given a string `s` and an integer `k`. You can choose any character of the string and change 
it to any other uppercase English character. You can perform this operation at most `k` times.

Return the length of the longest substring containing the same letter you can get after performing the above operations.

```
Example 1:

Input: s = "ABAB", k = 2
Output: 4
Explanation: Replace the two 'A's with two 'B's or vice versa.

Example 2:

Input: s = "AABABBA", k = 1
Output: 4
Explanation: Replace the one 'A' in the middle with 'B' and form "AABBBBA".
The substring "BBBB" has the longest repeating letters, which is 4.
There may exists other ways to achieve this answer too.
```

> Playground: [Leetcode 424](https://leetcode.com/problems/longest-repeating-character-replacement/description/)

---

### Basic Intuition

For any substring, keeping the most frequent character as-is minimizes the number of replacements. All the 
remaining characters can be replaced to make the entire substring consist of the same character.

![basic-intuition](/longest-repeating-character-replacement/basic-intuition.png)

**<span className="text-yellow-500">Therefore, a substring is eligible if:</span>** `the number of replacements 
required, i.e., (length of substring - frequency of the most frequent character) <= k`.
