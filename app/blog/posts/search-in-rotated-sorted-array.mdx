Given an array `nums`, sorted in ascending order and left rotated at an unknown index `k` 
(`1 <= k < nums.length`), and an integer `target`, return the index of `target` if 
it is in `nums`, or `-1` otherwise.

You must write an algorithm with `O(log n)` runtime complexity.

```
Example 1:

Input: nums = [4,5,6,7,0,1,2], target = 0
Output: 4

Example 2:

Input: nums = [4,5,6,7,0,1,2], target = 3
Output: -1

Example 3:

Input: nums = [1], target = 0
Output: -1
```

> **Playground**: [Leetcode 33](https://leetcode.com/problems/search-in-rotated-sorted-array/description/)

---

### Key Observations

For an array rotated at an unknown index k (`1 <= k < nums.length`), at least one half of the array will 
always be sorted in ascending order.

![key-observation-1](/search-in-rotated-sorted-array/key-observation-1.png)

---

### Suitable Approach - Binary Search

Use binary search to repeatedly eliminate the half that cannot contain the `target` until the target is 
found or no elements remain to be explored.

#### Algorithm

```java
1. Initialize two pointers, "start" and "end", to mark the subarray under consideration.

2. Keep performing the below operations while "start" <= "end", i.e., atleast one element exist 
   in the current subarray.
    3. Find the "middle" index of the current subarray.

    4. If "nums[middle]" (middle element of the current subarray) == "target", return the 
       "middle" index.

    5. If "nums[start]" (first element of the current subarray) <= "nums[middle]", the 
       left half of the subarray is sorted.
        6. If "target" < "nums[start]" or "target" > "nums[middle]", the "target" element must 
           lie exist in the right half. Move "start" to "middle + 1".
        7. Otherwise, the "target" lies in the left half. Move "end" to "middle - 1". 

    8. Otherwise if "nums[start]" > "nums[middle]", the right half is sorted.
        9. If "target" < "nums[middle]" element or "target" > "nums[end]" (last element of the 
           current subarray), the "target" must lie in the left half. Move "end" to "middle - 1".
        10. Otherwise, the target lies in the right half. Move "start" to "middle + 1".

11. If the "target" is not found, return -1.
```

#### Implementation

```java
public int search(int[] nums, int target) {

    // 1. Initialize two pointers, start and end, to mark the subarray under consideration.
    int start = 0, end = nums.length - 1;

    // 2. Keep performing the below operations while atleast one element exist in the current subarray.
    while (start <= end) {

        // 3. Find the middle index of the current subarray.
        int middle = (start + end) / 2;

        // 4. If the middle element of the current subarray == target element, return the middle index.
        if (nums[middle] == target) {
            return middle;
        }

        // 5. If the first element of the current subarray <= middle element, the left half 
        // of the subarray is sorted.
        if (nums[start] <= nums[middle]) {

            // 6. If target element doesn't lie in the left half, move start pointer to (middle + 1).
            if (target < nums[start] || target > nums[middle]) {
                start = middle + 1;
            } else { // 7. Otherwise, the target element can lie in the left half. Move end pointer to (middle - 1). 
                end = middle - 1;
            }
            

        } else { // 8. Otherwise, the right half is sorted.

            // 9. If the target element doesn't lie in the right half, move end pointer to (middle - 1).
            if (target < nums[middle] || target > nums[end]) {
                end = middle - 1;
            } else { // 10. Otherwise, the target element can lie in the right half. Move start pointer to (middle + 1).
                start = middle + 1;
            }

        }
        
    }   

    // 11. If the target element is not found, return -1.
    return -1;
        
}
```
