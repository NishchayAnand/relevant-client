Given an integer array `nums`, return all the triplets `[nums[i], nums[j], nums[k]]` such that 
`i != j`, `i != k`, and `j != k`, and `nums[i] + nums[j] + nums[k] == 0`.

> **NOTE**: The solution set must not contain duplicate triplets. The order of the output and the 
order of the triplets does not matter.

#### Example

```
Input: nums = [-1,0,1,2,-1,-4]
Output: [[-1,-1,2],[-1,0,1]]
Explanation:
- nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0.
- nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0.
- nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0.

The distinct triplets are [-1,0,1] and [-1,-1,2].
```

> **Solve Here**: [Leetcode 15](https://leetcode.com/problems/3sum/description/)

---

### Approach 1: Nested Loops

Use three nested loops to iterate through all possible triplets and keep track of the unique 
ones whose sum is `0`.

#### Algorithm

```
1. Initialize an empty set to store the unique triplets.
2. Iterate through the array using three pointers: i, j, and k:
    - For each triplet, check if the sum is equal to 0:
        - If the sum is equal to 0, store the triplet in a set and add it to the result set.
        - If the sum is not equal to 0, continue to the next triplet.
3. Convert the result set into list and return it.
```

#### Implementation

```java
public List<List<Integer>> threeSum(int[] nums) {
    Set<Set<Integer>> resultSet = new HashSet<>();
    for(int i = 0; i < nums.length - 2; i++) {
        for(int j = i + 1; j < nums.length - 1; j++) {
            for(int k = j + 1; k < nums.length; k++) {
                if (nums[i] + nums[j] + nums[k] == 0) {
                    Set<Integer> triplet = Set.of(nums[i], nums[j], nums[k]);
                    if(!resultSet.contains(triplet)) {
                        resultSet.add(triplet);
                    }
                }
            }
        }
    }
    
    List<List<Integer>> resultList = new ArrayList<>();
    for(Set<Integer> triplet : resultSet) {
        resultList.add(new ArrayList<>(triplet));
    }
    return resultList;
}
```
