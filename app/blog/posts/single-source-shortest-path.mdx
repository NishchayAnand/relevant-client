**Single Source Shortest Path (SSSP)** algorithms are the solution to this problem. They let you find the shortest 
distance from a given source vertex to every other vertex in a graph. 

Let's explore a few possible variations and understand how their approaches differ.

---

### Naive Approach: Bellmand-Ford

Bellman-Ford guarantees that one complete pass through all the edges of the graph, performing edge relaxation on 
each edge, discovers shortest paths containing at most one additional edge. This guarantee is based on the 
following two important observations:

1. **Optimal Substructure Property**: A shortest path from a source vertex to a destination is composed of 
shortest paths from the source to each of its intermediate vertices.

2. **Maximum Number of Edges in a Shortest Path**: In a graph with `(V)` vertices, a shortest path can contain at most 
`(V-1)` edges, provided there is no reachable negative-weight cycle. This is because a shortest path never needs to 
repeat a vertex.

#### Algorithm

Since each pass guarantees the discovery of shortest paths containing at most one additional edge, after `(V-1)` 
passes, it's guaranteed to have discovered the shortest distances from the source to every reachable vertex.
